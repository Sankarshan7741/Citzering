# Citzering
A simple web project that visualizes city-wise crime data (FIRs) on a 3D map and shows analytics on a dashboard. Built to practice web development, 3D mapping, and basic data visualization.

## About the Project
This project helps users see which cities have high or low crime rates using an interactive 3D globe. It color-codes locations based on FIR counts, detects your current location, and syncs data to a dashboard with charts and a searchable table.

## Features
- Interactive 3D map using Cesium.js
- Auto-detects user location & smoothly flies the camera to it
- UI with smooth CSS animations
- Dashboard with bar & doughnut charts (Chart.js)
- Searchable data table with color-coded status badges
- Data sync between pages using browser `localStorage`
- Responsive design that works on mobile & desktop

## How to Run
Use VS Code Live Server for the smoothest experience.
1. Download or clone this project folder.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox).
3. Allow location access when prompted (optional but recommended).
4. Click **"📊 View Dashboard"** to see charts & the data table.
